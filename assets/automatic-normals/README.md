# Generated automatic normals — recipe relief2

These files are derived from the original world/sprite artwork listed in manifest.json. Original artwork is unchanged. The pinned Sprite Fusion generator, its source/build hashes and licenses are retained under vendor/spritefusion. Each entry records source SHA-256, isolated frame layout, bounded normal detail and native relief size.

Normal PNGs are reusable estimates. Native-size relief WebP files are lossless RGBA-verified prepared artwork for the existing image-space normal-lighting contract, not new gameplay geometry or moving-light shaders. Custom authored normals take priority.

Regenerate with tools/bake-automatic-normals.cjs, then tools/compress-automatic-normals.py. Run tests/automatic-normal-assets1617.cjs plus the browser normal/lighting gates before packaging. UI, portraits and sky banks are not included. Details and limits: ITERATION-0.16.17.md.
