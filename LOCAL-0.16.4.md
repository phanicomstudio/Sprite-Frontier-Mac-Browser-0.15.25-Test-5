# Local Windows PC version — 0.16.4

October 26, 2026. Extract the complete Sprite-Frontier-Windows-0.16.4.zip, then open **Launch Sprite Frontier.cmd** or **Sprite Frontier.exe** inside that folder. Keep resources and the other supplied runtime files beside the executable. No Rust, Node installation or GitHub login is needed to play/edit this package. Runtime licenses and complete maintained source are included.

Choose **Isometric Textured Wilderness** in Active map, enter Playtest (F2), click the view to activate capture, press Space to draw if necessary, then use WASD, mouse aim, F/left click and wheel zoom. Escape pauses; F2 returns to editing. Existing 0.16.3 local projects use the same profile. Back up your authored maps with Export all maps.

Windows only is intentional for this requested milestone. Older milestone files are preserved. See ITERATION-0.16.4.md for camera-specific zoom behavior and RELEASE-VALIDATION-0.16.4.json for completed checks.
