# Scene inventory — 0.16.1

October 23, 2026. Supersedes the cramped 0.16.0 scene dock layout.

The wider left dock uses compact tool and selection rows, leaving more height for scene entries. Choose **Expand scene list** for a large inventory; close it with the same button or Escape. The original live list stays in place: search, Shift-range selection, Ctrl/Cmd toggling, deletion and Undo keep their existing behavior. The inspector remains accessible beside the expanded list.

This iteration changes editor layout only. Existing capabilities and sprite presentation remain intact. The compatible Windows profile remains Sprite-Frontier-0.16.0. Earlier releases and documentation are preserved.
