# Inventory D-pad controls — October 29, 2026

The upper and lower vertical bars of the original D-pad are invisible scroll buttons. Do not draw placeholder buttons, arrows, labels, backgrounds or borders over them. Left/right arms and the center are not scroll targets.

Regions use native 2475 × 3072 artwork coordinates, converted to percentages against the same image container. Up: x811, y2593, width78, height65. Down: x809, y2702, width78, height66. These replace the earlier oversized draft regions. Verify alignment in widescreen and 4:3 during integrated UI acceptance.

Keyboard focus may show an accessibility outline; ordinary pointer interaction preserves the original artwork. The combined update is still in development; this does not mark the inventory integration or release complete.
