# Local Windows version — 0.16.5

Extract the complete Windows ZIP and open Launch Sprite Frontier.cmd or Sprite Frontier.exe. Keep resources and the other runtime files beside the executable. The 0.16.3/0.16.4 save profile is retained.

Paired door return trips now remember the side you entered from and face you outward, for cinematic doors, DOOM melt, fades and cuts. Save playtest state to retain this history across sessions. Existing saves gain the history as doors are used. A blocked arrival rejects rather than placing you on the opposite side.

First-person zoom remains disabled. The 0.16.4 isometric input, zoom and sky-fog fixes are included. See ITERATION-0.16.5.md for behavior and compatibility.
