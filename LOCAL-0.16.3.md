# Local Sprite Frontier 0.16.3

Windows: open **Launch Sprite Frontier.cmd** or **Sprite Frontier.exe** in the Windows folder. No development tools are required.

Mac/browser: extract the complete ZIP and open **index.html** in a current browser. Keep its asset folders beside it.

The Windows version uses a separate 0.16.3 save profile. To bring an existing project across, export it from your previous version, then choose **Open Project** here. Previous versions and saves remain available.

The Git review is PR #6. See ITERATION-0.16.3.md for controls, atmosphere defaults, shadow budgets and known limits.
